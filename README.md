# Интерпретатор языка программирования

Интерпретатор собственного языка программирования "Blang" на C#.

## Сборка

### Требования
- .NET SDK 9.0 или выше
- IDE (Visual Studio / Rider / VS Code) или командная строка

### Компиляция
```
dotnet build
```
### Запуск тестов
``` 
dotnet test
```
### Запуск проекта
``` 
cd .\src\Interpreter\
dotnet run test.blang
```

## Архитектура проекта

Выполнение программы на языке Blang проходит через классический конвейер с обходом дерева:

1. **Lexer (Лексический анализатор)** — преобразует исходный код в поток токенов.
2. **Parser (Синтаксический анализатор)** — строит абстрактное синтаксическое дерево (AST) методом рекурсивного спуска.
3. **Semantics (Семантический анализатор)** — проверяет корректность типов, областей видимости (lexical scoping), арность функций и соблюдение правил возврата значений.
4. **Execution / AST Evaluator (Исполнитель AST)** — обходит узлы AST с помощью паттерна **Visitor** (`IAstVisitor`). Для вычисления выражений используется стек значений (`Stack<RuntimeValue>`), а управление областями видимости (`Scope`), таблицей функций и потоком выполнения (`break`, `continue`, `return`) реализовано через объект контекста (`Context`).

## Пример кода на Blang
```blang
func num factorial(num n) {
    if (n <= 1) {
        return 1;
    };
    return n * factorial(n - 1);
};

num fnumber;
write("Введите число (от 0 до 10): ");
readln(fnumber);

if (fnumber < 0) {
    writeln("Ошибка: факториал отрицательного числа не определен!");
} else {
    if (fnumber > 10) {
        writeln("Ошибка: число слишком большое для вычисления!");
    } else {
        num result = 1;
        num i = 1;

        while (i <= fnumber) {
            result = result * i;
            i = i + 1;
        };

        writeln("Факториал ", fnumber, " (через цикл) = ", result);
        writeln("Факториал ", fnumber, " (через рекурсию) = ", factorial(fnumber));
    };
};
```
